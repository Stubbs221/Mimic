# Contributing

Describe the problem and expected result in an issue or pull request. Keep changes focused and run the tests relevant to the behavior you change, using disposable data rather than real team workflows.

Mimic uses native SwiftUI/AppKit. Keep interface text in localization resources. Changes to the web panel must include its regenerated bundled HTML and retained third-party notices.

Do not commit private profiles, credentials, diagnostics, personal agent configuration or internal project documents. Do not run live Bootstrap, generators, project cleanup or remote CI as acceptance checks without explicit authorization.

Keep the Russian and English README aligned. Original contributions use the [MIT license](LICENSE); preserve third-party notices and existing authorship. New first-party text files name Василий Маслов and their actual creation date in a valid comment.

Include expected/actual behavior and relevant validation in your pull request. Use [SECURITY](SECURITY.md) for vulnerability reports.

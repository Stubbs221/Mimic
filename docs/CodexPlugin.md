# Mimic в Codex

Нужны установленное приложение Mimic, доверенный профиль команды и локальная версия Codex с поддержкой плагинов и MCP Apps.

## Подключение

В настройках Mimic выберите подключение Codex. Приложение экспортирует локальный плагин и подключает его на этом Mac. Node.js или отдельный веб-сервер для работы панели не нужны. Профиль команды и учётные данные не входят в плагин.

Откройте панель «Задачи Mimic» в нужном чате Codex. Каждый чат привязан к своему Git-проекту; выбор проекта в десктопном приложении не переключает другие чаты. Панель и десктоп используют общую очередь локальных задач.

## Работа

В панели доступны действия совместимого профиля, прогресс, история, терминалы задач и наблюдение CI. Запуск действий требует соответствующего запроса пользователя. Импорт профиля сам по себе не разрешает агенту выполнять его команды.

Раскладки десктопа и Codex настраиваются независимо. Выбранные формы и задачи сохраняются в контексте чата. Приватные данные проекта не следует переносить в публичные отчёты или изображения.

## После обновления

Ранее подключённый плагин обновляется при первом запуске новой сборки Mimic. Если панель сохранила старый интерфейс, закройте и откройте её снова. Codex принудительно не перезапускается.

# Mimic 1.7.0

- Исправлено применение профильных настроек: контрольная сумма состояния больше не вызывает ошибку `parameter`.
- Черновики сохраняются при неудачном перечитывании, закрытии представления и потере связи с Codex-панелью.
- Восстановление связи продолжает наблюдение за исходным запросом без повторной отправки изменений. Поздние ответы не подменяют другую цель или новый контекст.
- Настройки подтверждаются только после успешного завершения процесса. Сервисные команды больше не используют старое окружение после ошибки чтения.
- Усилены проверка структурированных результатов и защита от повторного выполнения при повреждении локального журнала запросов.
- Исправлены зависания MCP при передаче сообщений и ожидание штатного выхода приложения при локальном обновлении.

Apple Silicon · macOS 14+ · build 170. Профиль команды устанавливается отдельно. Для экрана Simulator требуется Xcode 27+.

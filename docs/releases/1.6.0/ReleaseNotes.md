# Mimic 1.6.0

- Задача Jira и связанные документы Confluence рядом с рабочими инструментами: определение задачи из ветки, поиск и ручной выбор.
- Карточки задачи Mini и Full по макету 02 сохраняют общую высоту. Контекст копируется прямо из карточки; документы открываются по запросу, дополнительные действия доступны в меню ключа.
- В Codex исправлены размеры и оформление кнопок, сохранение клавиатурного фокуса при обновлении и поведение списка документов.
- Черновик отчёта собирает выбранные результаты проверок для ручной отправки. Mimic не публикует комментарии и не изменяет Jira или Confluence.
- Исправлены ресурсы установленного приложения и блокировка переключения ветки фоновым снимком симулятора. Улучшены статистика AI, обнаружение физических устройств, ввод терминала и наблюдение CI при простое.

Apple Silicon · macOS 14+ · build 161. Профиль команды устанавливается отдельно. Для экрана Simulator требуется Xcode 27+.

# Mimic 1.6.0: иллюстрированные материалы

Предварительный кандидат 1.6.0, build 160 от 13.10.2026. Опубликованный выпуск — [1.6.0 / 161](https://github.com/Stubbs221/Mimic/releases/tag/v1.6.0); изображения карточки задачи в этих материалах предшествуют макету 02. Три переработанных документа на русском; HTML и PDF используют один текст.

| Документ | HTML | PDF |
| --- | --- | --- |
| Знакомство за 2–3 минуты | [HTML](quick-preview.html) | [PDF](quick-preview.pdf) |
| Полный обзор | [HTML](overview.html) | [PDF](overview.pdf) |
| Установка и ежедневная работа | [HTML](guide.html) | [PDF](guide.pdf) |

[Все HTML одним архивом](Mimic-1.6.0-HTML.zip). Распакуйте рядом и откройте любой документ. Стили, изображения и увеличение встроены; интернет нужен только для внешних ссылок. Escape закрывает просмотр иллюстрации и возвращает фокус.

Материалы показывают оформление, инструменты, CI, Jira/Confluence и Simulator предварительной сборки 160. Актуальные изменения опубликованной сборки 161 — в [заметках выпуска](ReleaseNotes.md).

Иллюстрации - настоящие production views/components с безопасными фикстурами, без живых операций, аккаунтов или устройств. [Происхождение](../../images/README.md). Нотарификация не подтверждает live-производительность или работу на другом оборудовании.

Архивные материалы [1.5.0](../1.5.0/README.md) и [1.4.0](../1.4.0/README.md) сохранены без изменения.

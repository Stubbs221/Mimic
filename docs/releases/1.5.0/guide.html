01 · Перед началом

Что понадобится.

⌘

Mac и Xcode

Выпуск предназначен для Apple Silicon; минимальная система — macOS 14. Живой запуск на macOS 14 и Intel отдельно не подтверждён. Для разработки нужны Xcode и инструменты профиля.

◈

Доверенный профиль

Получить .mimicprofile у Василия Маслова. Профиль поставляется отдельно от приложения и содержит сценарии команды. Токены в профиль не добавляй.

Для встроенной панели нужна локальная версия Codex с поддержкой плагинов и MCP Apps. Для экрана Simulator — Xcode 27+. CI можно настроить позже; при необходимости используй рабочую сеть/VPN команды.
02 · Установка

Готовое приложение.
Без сборки из исходников.

  1. 01

    Скачай пакет со страницы релизов

    Открой GitHub Releases ↗. Скачай MimicSetup-1.5.0.zip для первой установки и распакуй архив.

  2. 02

    Установи Mimic

    Запусти setup-mimic.command: по умолчанию он устанавливает приложение в ~/Applications. Альтернатива — перенести Mimic.app в доступную папку Applications вручную.

  3. 03

    Открой приложение

    Запусти Mimic из Applications. Его значок появится в строке меню macOS. До импорта совместимого профиля будет показана первоначальная настройка.

Готово: Mimic открыт, доступна настройка профиля. Если macOS блокирует запуск, проверь источник и целостность пакета; не отключай системную защиту. Сохрани точный текст сообщения для разбора с владельцем инструмента.
03 · Профиль и среда

Свяжи инструменты
с рабочим проектом.

  1. 01

    Импортируй профиль команды

    В первоначальной настройке либо Настройки → Профиль и среда → Импортировать профиль… выбери пакет от Василия Маслова. Ошибка импорта сохраняет прежний активный профиль.

  2. 02

    Добавь checkout

    В том же разделе нажми Добавить checkout…, выбери локальный Git-проект, затем нужный проект в списке. Выбери checkout своего проекта.

  3. 03

    Выбери Apple-проект

    Нажми Workspace / project → Выбрать…. Выбери существующий .xcworkspace или .xcodeproj своего проекта. Используй актуальные пути и Apple target из конфигурации команды.

  4. 04

    Задай Xcode

    Нажми Выбрать Xcode… или оставь Системный. Для встроенного экрана Simulator нужен Xcode 27+. Apple target задаётся при выборе workspace/project.

Схема работы

Профиль и среда

  1. Импортировать профиль…
  2. Добавить checkout…
  3. Workspace / project и Xcode
Готово: видны название и версия профиля, выбранный checkout, workspace/project и Xcode. Профиль один для Mac; проекты десктопа и чатов Codex выбираются отдельно. Совместимый пакет использует manifest 2 и interface 1.
Доверие к профилю. Импорт не запускает команды и не обращается в сеть. Адаптеры — исполняемые программы: проверяй происхождение профиля. Новая версия подключается повторным импортом; уже принятые задачи сохраняют свою ревизию.
04 · Codex

Подключи панель
к нужному чату.

  1. 01

    Экспортируй локальный плагин

    В Mimic открой Настройки → AI и Codex. В блоке Панель Mimic в Codex нажми Подключить к Codex и следуй подсказкам подключения.

  2. 02

    Открой Mimic в рабочем чате

    В чате проекта попроси: «Открой панель Mimic для текущего checkout». При вызове open_panel используется абсолютный рабочий каталог именно этого чата.

  3. 03

    Проверь контекст

    В шапке или подробностях проекта проверь checkout, ветку и Xcode. Выбор проекта в десктопе не переключает проект чата. Если привязки нет, используй Подключить проект чата.

Схема работы

AI и Codex

  1. Подключить к Codex
  2. Открыть панель в чате
  3. Подключить проект чата
Готово: панель открыта рядом с чатом и показывает его проект. Для работы панели отдельный Node.js или веб-сервер не нужен. Подключение CLI для анализа ошибок — отдельная настройка; авторизацию в CLI проходи самостоятельно.
05 · CI-подключения

GitLab и Jenkins.
Credentials — в Keychain.

  1. 01

    Открой настройки CI

    Перейди в Настройки → CI. Получи адреса серверов и права доступа у команды; вводи их только в нативные поля Mimic.

  2. 02

    Настрой GitLab

    Укажи сервер и идентификатор проекта из конфигурации команды, затем свой Personal access token с правом read_api. Нажми Проверить, после успешной проверки — Сохранить.

  3. 03

    Настрой Jenkins

    Укажи сервер, логин Jenkins и личный API-токен. Логин берётся из адреса профиля /user/имя/security/ и может отличаться от почты. Снова: Проверить → Сохранить.

  4. 04

    Выбери нужные кнопки запуска

    Если нужны Quality Gates или Beta, включи Показывать запуск Quality Gates и Показывать запуск Beta. История продолжает показывать все типы прогонов.

Схема работы

Настройки → CI

  1. Адреса и права от команды
  2. Нативные формы credentials
  3. Проверить → Сохранить
Готово: у сервиса указан статус «Подключено». «Проверить» не заменяет «Сохранить». При уже настроенном подключении пустое поле токена сохраняет прежний токен. CI можно пропустить и вернуться к нему позже.
Не передавай токены через чат, HTML, профиль или скриншоты. Не нажимай «Перечитать токен» ради иллюстрации или передачи данных.
06 · Ежедневная работа

Выбери задачу.
Проверь область действия.

СценарийКак работать
BootstrapОткрой нужную платформу, выбери этапы подготовки и проверь предупреждение о закрытии Xcode. Запускай явно. Следи за этапами и терминалом; при необходимости отмени задачу.
CelestialОткрой инструмент, выбери UI-компонент/Sicilia/Galera и введи имя. Нажми «Проверить будущие файлы», просмотри план и только затем запусти создание. После изменения имени проверка нужна снова.
Babylon, Protobuf, SwiftFormatОткрой форму из каталога или избранного, проверь checkout и область действия профиля. После запуска форма покажет очередь, состояние, отмену и переход к записи истории.
ОчисткиПроверь назначение и область удаления в форме. Полная очистка и DerivedData меняют локальные кэши; запускай только когда это нужно для задачи.
Сборки и тестыВыбери workspace/project, схему и конкретный iOS/tvOS Simulator. Для проверки изменений выбери необходимые test identifiers; не запускай весь набор по умолчанию.
UI-тесты в CIВыбери удалённую ветку и план: SMOKE, FUNCTIONAL, STATS или FULL, если они доступны в текущей конфигурации сервера. Проверь параметры перед отправкой.
Quality Gates / BetaВ Quality Gates выбери проверки. В Beta просмотри серверные defaults. После отправки наблюдай конкретный прогон; при неизвестном результате не повторяй отправку вслепую.
Схема работы

Celestial

  1. Тип компонента и имя
  2. Проверить будущие файлы
  3. Создать после проверки
Очередь общая. Задача может ждать работу другого проекта. Уже принятая задача фиксирует свой контекст и профиль. Импорт профиля сам по себе не разрешает агенту запускать действия: формулируй нужное действие явно.

Самостоятельная сборка и точные тесты

Открой параметры карточки «Сборки»: проверь checkout, Xcode, схему и Simulator. Выбери «Собрать», «Собрать и запустить» или «Тесты». В каталоге отметь только нужные suites/identifiers; при необходимости введи точный список вручную. Для готового результата используй отдельный запуск. Проверь итог и артефакты в истории.

Проверка с агентом

Наблюдение.
Действие. Доказательство.

Явный сценарий проверки интерфейса с отчётом и записью.

  • Укажи разрешённые действия, критерии результата и конкретное устройство. Агент получает актуальные capabilities проекта.
  • Цикл проверки связывает наблюдения, действия и доказательства. Устаревшие ответы не меняют текущий сценарий.
  • Попроси агента начать проверку на конкретном устройстве и явно включить запись. Он использует start_simulator_check и start_simulator_recording; stop_simulator_recording останавливает видео, finish_simulator_check завершает журнал. Отчёт связывает наблюдения, действия и артефакты. Запись требует уже доступного native-видеопотока.
  • Неопределённый исход отмечается явно. Проверка не выдаёт отсутствие ошибки за доказанный PASS.
07 · Simulator

Смотри и управляй
из панели Codex.

  1. 01

    Открой блок Simulator

    Используй выбранный Xcode 27+; если Xcode не задан, используется системный. При первом доступе выбери существующий Apple workspace в нативном окне Mimic и пройди системное подтверждение.

  2. 02

    Выбери устройство

    Используй группы «Запущенные», «Недавние» или поиск по имени/UUID. Единственное запущенное устройство может подключиться автоматически. При выборе выключенного устройства Mimic запускает его.

  3. 03

    Управляй экраном

    Клик — нажатие, протягивание — свайп, колесо — прокрутка. После фокуса на экране доступны ввод текста и вставка. Над экраном находятся выбор устройства, отключение, Home и поворот; разворачивание — в меню.

  4. 04

    При необходимости установи приложение

    «Установить и запустить» использует актуальный проект текущего чата, его профиль и Xcode. Просмотр экрана доступен и без checkout; установка требует полного контекста.

Режим и ограничения.

  • «Видео» — H.264 по приватному MCP-каналу. «Кадры» / «Резервные кадры» — автоматические снимки Apple MCP.
  • При скрытии или сворачивании панели кадры и ввод останавливаются; при возвращении просмотр возобновляется.
  • Backspace и Return поддерживаются. Tab перемещает фокус панели; навигационные клавиши не отправляются устройству. Forward Delete не подтверждён.
  • Во время команды агента ручной ввод блокируется. Escape закрывает меню или возвращает обычный размер.
FPS и задержка находятся в «Диагностике». Video latency — оценка; для кадров показывается интервал «запрос → показ». До достаточного замера значения могут быть «—».
08 · Ветки

Переключай локальный checkout
осознанно.

  1. 01

    Открой выбор ветки

    Нажми ветку в шапке Tile Grid. Выбор ветки для CI не меняет локальный checkout.

  2. 02

    Выбери режим rebase

    «Rebase на develop» по умолчанию выключен. Если включить, Mimic получит свежий origin/develop и подготовит целевую ветку во временном worktree перед переключением.

  3. 03

    Проверь результат

    Tracked/untracked изменения сохраняются и восстанавливаются через stash; именованный резерв остаётся. Ignored-файлы в этот перенос не входят. При конфликте используй отдельный чат Codex с подготовленным контекстом.

Пока переключение не завершено, локальные задачи Mimic блокируются. После перезапуска неопределённая операция требует проверки и не продолжается автоматически. Если запрос конфликта только подготовлен в новом чате, нажми «Отправить» самостоятельно.

Настрой Tile Grid

«+» добавляет отсутствующую плитку, «−» включает выбор плитки для удаления. Удерживай свободную поверхность для переноса. Escape отменяет текущий перенос или выбор.

Закрепи три инструмента

Открой каталог «Инструменты». Звёздочки задают избранное, стрелки — порядок. Состав общий для приложения и панелей Codex этого Mac.

  • Анализ ошибки запускай по необходимости: выбери фрагмент диагностики, проверь его на секреты и отправь через настроенный CLI. Самостоятельно пройди авторизацию выбранного CLI.
10 · История и обновления

Результаты сохраняются.
Обновление подождёт.

  • История внизу панели открывает задачи и сборки; в нативной панели доступна ⌘1. «Показать ещё» раскрывает следующие записи.
  • Активную задачу можно отменить штатной кнопкой. Неопределённый или прерванный запуск не перезапускай без проверки состояния.
  • Настройки → Основные → Проверить обновления запускает ручную проверку. Автопроверка выполняется раз в час.
  • Установка ждёт локальные задачи и операции, создаёт backup и сохраняет профиль, настройки и историю. Отправленный CI восстанавливается для наблюдения без повторной отправки.
  • После запуска новой сборки плагин Codex обновляется. Если интерфейс прежний, закрой и снова открой панель; при необходимости переподключи плагин.
Схема работы

Настройки → Основные

  1. Проверить обновления
  2. Дождаться завершения локальной работы
  3. Backup и перезапуск
Старым версиям без обновлятора нужна одна ручная установка. Для ручной замены заверши работу и штатно выйди из Mimic. MimicSetup-<version>.zip — первая установка; Mimic-<version>.zip — приложение для обновления. Приватный профиль обновляется отдельным импортом.
11 · Безопасность

Перед передачей данных
проверь содержимое.

  • Credentials вводятся в нативных формах и хранятся в Keychain. Не включай их в профиль, чат, issues или документы.
  • Вывод Bootstrap и полной очистки не сохраняется на диск. Ограниченные терминальное представление и диагностика в памяти исчезают после выхода.
  • Сохраняемые логи инструментов ограничиваются и очищаются. Очистка известных форматов credentials не даёт полной гарантии: просмотри лог или скриншот перед пересылкой.
  • Каталог агента содержит разрешённые действия и параметры, без команд, содержимого адаптеров и сервисных адресов. Контекст проекта и явно запрошенная диагностика могут передаваться агенту.
  • Поток экрана и ключи просмотра идут приватным каналом панели. При явном запросе наблюдения агент может получить снимок и иерархию устройства.
  • Импортируй только доверенный профиль: его адаптеры являются исполняемыми программами и не изолированы sandbox.
12 · Частые вопросы

Если что-то
не получилось.

Вместо задач открывается первоначальная настройка

Выбери Git checkout и импортируй совместимый профиль команды. При отказе импорта получи актуальный пакет у Василия Маслова. CI необязателен; профиль обязателен.

Инструмент или сборка недоступны

Проверь проект, Xcode, workspace/project, Apple target и инструменты, требуемые профилем. Для сборки нужен конкретный Simulator destination, для тестов — выбранные identifiers. Не запускай Bootstrap автоматически в ответ на недоступность.

Панель Codex показывает старую версию

Запусти обновлённый Mimic, дождись обновления плагина и открой панель заново. При необходимости переподключи плагин в настройках Codex. Закрытие панели само по себе не завершает MCP-соединение.

Обновление ожидает или не устанавливается

Ожидание нормально во время локальной работы или неопределённой операции. Заверши работу штатно. При сетевой ошибке повтори проверку позже; при ошибке доступа используй доступную папку Applications и опубликованную инструкцию ручной замены.

CI не подключается или неизвестен результат отправки

Проверь рабочую сеть, права, адреса и логин. «Проверить» не заменяет «Сохранить». При неизвестном результате сначала проверь конкретную очередь/прогон на сервере: не отправляй дубликат вслепую.

Какие данные приложить к сообщению о проблеме?

Версии Mimic, macOS, Xcode, архитектуру, ожидаемый результат и короткие шаги. Перед передачей удали секреты и личные данные. Для уязвимостей используй приватный маршрут из SECURITY в репозитории.

Готово к рабочему дню.

Профиль и помощь с конфигурацией — у Василия Маслова. Все возможности и короткое знакомство доступны в соседних документах.

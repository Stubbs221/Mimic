[Скачать все HTML одним архивом](https://github.com/Stubbs221/Mimic/raw/refs/heads/main/docs/releases/1.4.0/Mimic-1.4.0-HTML.zip). Распакуйте файлы в одну папку и откройте `quick-preview.html`, `overview.html` или `guide.html` в браузере. Сервер, установка пакетов и интернет для просмотра не требуются. Кнопки увеличивают изображения; Escape закрывает просмотр. Оглавление и меню связывают документы. Ссылки на GitHub требуют интернета.

GitHub показывает HTML как исходный код: скачайте его кнопкой Download raw file или по ссылкам выше. Для просмотра прямо на GitHub выбирайте PDF.

Материалы описывают выпущенный Mimic 1.4.0/140. macOS-скриншоты сняты на установленной 1.4.0; Codex и Simulator — реальные development-снимки Tile Grid до финальной сборки. Они не подтверждают видеопроизводительность релиза. Скриншоты взяты только из [публичного очищенного набора](../../images/README.md); исходные рабочие снимки, внутренние пути, адреса сервисов и приватные профили сюда не входят. Иллюстрации настроек обозначены как схемы, а не снимки интерфейса.

Палитра B: кремовый фон, фиолетовый акцент, лавандовые, мятные, персиковые и голубые карточки. Каждый HTML содержит стили, скрипты и изображения; PDF подготовлены из той же редакции для печати и пересылки.

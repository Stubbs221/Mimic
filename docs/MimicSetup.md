# Установка Mimic

Mimic 1.9.0 (сборка 190) для Apple Silicon. Пакет подписан Developer ID и прошёл нотарификацию Apple; Gatekeeper принимает нотарифицированный пакет. Минимальная версия системы — macOS 14; запуск на macOS 14 и Intel пока не проверен. Интерфейс — на русском.

## Установка и первый запуск

1. Скачайте `MimicSetup-1.9.0.zip` на [странице выпуска 1.9.0](https://github.com/Stubbs221/Mimic/releases/tag/v1.9.0) и распакуйте архив.
2. Запустите `setup-mimic.command`: по умолчанию он устанавливает приложение в `~/Applications`. Можно также перенести `Mimic.app` в Applications вручную.
3. Откройте Mimic из Applications. Приложение появится в строке меню.
4. Выберите Git checkout, импортируйте доверенный `.mimicprofile` вашей команды и задайте Xcode и Apple target.
5. При необходимости подключите Codex и Jenkins/GitLab через настройки. CI-подключения можно пропустить.

Без совместимого профиля вместо рабочей панели отображается первоначальная настройка. Приложение и профиль устанавливаются отдельно. Учётные данные CI вводятся в нативной форме и сохраняются в Keychain. Используйте инструкции вашей команды при отдельной миграции её профиля или данных.

## Обновления

Основное оформление — Tile Grid. В настройках → «Оформление» доступен общий для десктопа и Codex выбор «Tile Grid», «Прежний интерфейс», «Windows 95» и «Windows XP». Раскладки десктопа и Codex независимы. Переключение сохраняет настройки, черновики, раскладки и работающие задачи. Во всех оформлениях настройки объединены в разделы: «Основные», «Оформление», «Профиль и среда», «AI и Codex», «CI» и «Диагностика». Общий профиль Mimic отделён от выбранного checkout, workspace/project и Xcode. На узкой панели или при крупном тексте раздел выбирается через меню. У Tile Grid экспресс-меню открывается отдельной панелью; нажмите Escape, чтобы закрыть её и вернуть фокус. Прежнее оформление сохраняет системное экспресс-меню.

В десктопе Win95/XP поля, выпадающие списки и checkbox используют оформление R1. В списках доступны стрелки и поиск по первым буквам; Enter подтверждает выбор, Escape отменяет. Подсказка появляется через 500 мс наведения, а у сфокусированного элемента вызывается сразу по ⌘/. Escape закрывает подсказку. Переключение темы сохраняет введённый текст, выделение и незавершённый ввод IME.

В Win95/XP собственные окна настройки, карты интерфейса и учётных данных, окна активности, меню, popover и подтверждения также используют R1. Заголовки и кнопки окна сохраняют обычные действия закрытия, сворачивания и изменения размера. В меню доступны стрелки, Home/End, поиск по первым буквам и переходы в подменю; Enter выбирает, Escape отменяет. Системные панели macOS, обновлятор, веб-страница входа и внешнее окно Simulator сохраняют собственное оформление. В AI-плитке индикаторы лимита также используют сегменты Win95/XP; между документом и ретро-полосой прокрутки сохранён отступ.

Версии со встроенным обновлятором проверяют новые выпуски раз в час. Автоматическое обновление можно отключить; ручная проверка доступна в настройках приложения.

Версия, номер сборки и авторство находятся в блоке «О приложении» в самом низу основных настроек Mimic. В панели Codex этот блок расположен в конце меню «Настройки» и показывает версию работающего приложения.

После загрузки установка ждёт завершения локальных задач, сборок, AI и операций Simulator. Работающие задачи не отменяются. Перед заменой создаётся резервная копия; профиль, настройки и история сохраняются. Наблюдение уже отправленных CI-прогонов восстанавливается без повторной отправки.

Подключённый плагин Codex обновляется при первом запуске новой сборки. Если Mimic попросит, закройте и заново откройте панель в Codex. Приватный профиль обновляется отдельным импортом.

Прежние версии без обновлятора требуют одной ручной установки. Для ручной замены сначала завершите задачи и штатно выйдите из Mimic. При отказе доступа установите приложение в доступную папку Applications.

На странице выпуска `MimicSetup-<version>.zip` предназначен для первой установки, а `Mimic-<version>.zip` содержит приложение для автообновления или ручной замены. Файл `SHA256SUMS` позволяет проверить скачанный ZIP командой `shasum -a 256 -c SHA256SUMS`, если оба архива находятся рядом с ним. Используйте архивы только со страницы нужного выпуска; профиль команды в них не входит.

## MCP для Codex и Claude Code

Mimic 1.5.0 с `get_state.capabilities.buildWorkflowVersion = 1` позволяет агенту привязать свой checkout через `bind_project`, проверить готовность, запустить сборку или конкретные тесты, дождаться их завершения и получить структурированный результат. В Codex используйте подключение плагина из настроек Mimic. Для Claude Code подключите helper установленного приложения:

```sh
claude mcp add --scope user --transport stdio mimic -- /Applications/Mimic.app/Contents/Helpers/MimicMCP
```

Подставьте фактический путь Mimic.app. После переподключения Claude повторно привязывает checkout; выбранный проект десктопа не становится проектом агента. Проверки остаются в существующей истории. Поручение «проверь» не разрешает правки; «исправь и проверь» разрешает релевантные правки и повтор согласованных проверок. [Полная инструкция](AgentChecks.md).

## Нужна помощь

Профиль получите у команды. Обычные проблемы описаны в руководствах на странице проекта: https://github.com/Stubbs221/Mimic . При сообщении о проблеме укажите версию Mimic, macOS, Xcode и архитектуру; удалите приватные данные из изображений и логов.

## Сборки, запуск и выбранные тесты

Схемы, конфигурации и совместимые устройства сохраняются между запусками Mimic. При запуске выбранный подготовленный проект проверяется в фоне; сохранёнными параметрами можно пользоваться сразу. Обычные изменения исходников не сбрасывают этот кэш. Изменения настроек проекта, версии Xcode и состава симуляторов обновляют соответствующие данные; «Обновить схемы и устройства» принудительно перечитывает каталог. Поиск работает по загруженным данным. Перед сборкой Mimic заново проверяет устройства выбранной схемы, используя неизменившийся список схем и конфигураций из кэша. Перечисление тестов остаётся отдельным явным действием.

Mini и Full позволяют работать без раскрытия подробностей. Во время работы кнопки запуска заменяются этапом, прогрессом и отменой; высота плашки сохраняется общей для сетки. «Собрать» проверяет сборку, «Собрать и запустить» передаёт выбранные схему и Simulator в Xcode и запускает приложение с подключённым отладчиком. Mimic сам открывает проект в выбранном Xcode; при первом запуске macOS попросит разрешить Mimic управлять Xcode. Процент компиляции доступен после разрешения в «Универсальном доступе»; без него видны операции Xcode. В Full схема и устройство выбираются прямо на плашке; в Mini нажмите строку параметров. Если настройки устарели, выберите совместимые значения во всплывающем окне. Способ сборки и конфигурация находятся в дополнительных настройках. Если схема создаёт несколько приложений, выберите продукт.

«Тесты» открывает каталог с поиском, группировкой и отметками. Открытие ничего не запускает. «Загрузить список тестов» может собрать тестовые продукты, но не выполняет тесты. «Запустить выбранные тесты» передаёт только отмеченные identifiers. Ручной ввод доступен дополнительно. Настройки и выбор общие для Mac и Codex; после смены проекта, ревизии, Xcode, схемы или устройства список требует обновления.

Во время работы плашка показывает действие, инициатора, этап, время, прогресс и отмену. Запуски агента входят в ту же очередь. Отдельная плавающая плашка имеет ширину 360 pt и показывает завершённые этапы или выбранные тесты обычной шкалой. Внутри CLI-сборки видны операция Xcode и число успешно завершённых операций; неизвестный общий объём компиляции не превращается в выдуманный процент. Длинные параметры сокращаются, полное значение доступно в подсказке. В плашке доступны отмена, выбор приложения при нескольких продуктах, вывод и скрытие; скрытие не отменяет работу. Пин отключает автоскрытие после завершения, повторное нажатие включает его обратно; назначение объясняет подсказка. Без пина плашка скрывается через пять секунд после успеха или отмены, при ошибке остаётся видимой. Extended сохраняет вкладки сборки, запуска и тестов; подробности результата и полный лог открываются отдельно. Bootstrap автоматически не запускается.

## Обновление данных и нагрузка

При открытии Mimic сразу показывает сохранённые значения и проверяет каталог Xcode в фоне. Открытие параметров переиспользует неизменившийся каталог; ручное обновление перечитывает его принудительно. Выполнение проверяет актуальный контекст и устройства выбранной схемы заново. Каталог старше десяти минут отмечается как устаревший. AI-статистика автоматически обновляется раз в пять минут, также доступно ручное обновление.

Во время загрузки схем и устройств в Mini, Full и подробном виде показаны текущий этап, его номер, прошедшее время и шкала завершённых этапов. Время не увеличивает заполнение шкалы. При наличии сохранённых параметров действия остаются доступны.

Плашка «Окружение» содержит поля «Сабсайт», «Аппверсия», «Имя куба» и кнопки «Сбросить», «Принять», «Обновить». Выбора приложения на ней нет. Значения читаются по кнопке «Обновить»; при конфликте перечитайте их перед применением.

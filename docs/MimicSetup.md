# Установка Mimic

Mimic 1.3.1 для Apple Silicon. Минимальная версия системы — macOS 14; запуск на macOS 14 и Intel пока не проверен. Интерфейс — на русском.

## Установка и первый запуск

1. Получите `MimicSetup-1.3.1.zip` на https://github.com/Stubbs221/Mimic/releases/latest и распакуйте архив.
2. Запустите `setup-mimic.command`: по умолчанию он устанавливает приложение в `~/Applications`. Можно также перенести `Mimic.app` в Applications вручную.
3. Откройте Mimic из Applications. Приложение появится в строке меню.
4. Выберите Git checkout, импортируйте доверенный `.mimicprofile` вашей команды и задайте Xcode и Apple target.
5. При необходимости подключите Codex и Jenkins/GitLab через настройки. CI-подключения можно пропустить.

Без совместимого профиля вместо рабочей панели отображается первоначальная настройка. Приложение и профиль устанавливаются отдельно. Учётные данные CI вводятся в нативной форме и сохраняются в Keychain. Используйте инструкции вашей команды при отдельной миграции её профиля или данных.

## Обновления

Версии со встроенным обновлятором проверяют новые выпуски раз в час. Автоматическое обновление можно отключить; ручная проверка доступна в настройках приложения.

После загрузки установка ждёт завершения локальных задач, сборок, AI и операций Simulator. Работающие задачи не отменяются. Перед заменой создаётся резервная копия; профиль, настройки и история сохраняются. Наблюдение уже отправленных CI-прогонов восстанавливается без повторной отправки.

Подключённый плагин Codex обновляется при первом запуске новой сборки. Если Mimic попросит, закройте и заново откройте панель в Codex. Приватный профиль обновляется отдельным импортом.

Прежние версии без обновлятора требуют одной ручной установки. Для ручной замены сначала завершите задачи и штатно выйдите из Mimic. При отказе доступа установите приложение в доступную папку Applications.

## Нужна помощь

Профиль получите у команды. Обычные проблемы описаны в руководствах на странице проекта: https://github.com/Stubbs221/Mimic . При сообщении о проблеме укажите версию Mimic, macOS, Xcode и архитектуру; удалите приватные данные из изображений и логов.

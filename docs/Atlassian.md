# Jira и Confluence

Плитка «Задача» показывает задачу из текущей ветки, описание, статус и связанные документы. Mini и Full сохраняют общую высоту 160 и позволяют сразу скопировать контекст. Кнопка «Документы» открывает список связанных страниц во всплывающем окне у карточки. Меню ключа задачи содержит открытие Jira, поиск, требования, черновик отчёта, обновление и подключение. Добавьте плитку через «Новое действие → Задача»; обновление сохраняет существующие раскладки.

Если в ветке несколько ключей, выберите задачу. Поиск принимает ключ, ссылку или текст. Ручной выбор принадлежит текущему чату или десктопной панели. После смены ветки Mimic заново определяет контекст. Данные кэшируются на пять минут; кнопка обновления запрашивает их сразу. При ошибке прежние данные помечаются как устаревшие.

## Профиль и вход

Владелец доверенного `.mimicprofile` добавляет `services.atlassian` в `profile.json`. Профиль остаётся ZIP-пакетом с прежними адаптерами. Фрагмент объекта `services`:

```json
{
  "atlassian": [{
    "id": "team",
    "title": "Команда",
    "deployment": "dataCenter",
    "authentication": "webSession",
    "jiraURL": "https://jira.example.com",
    "confluenceURL": "https://docs.example.com/wiki",
    "projects": ["APP"],
    "spaces": ["APP"],
    "requirementFields": ["customfield_10001"]
  }]
}
```

`projects`, `spaces`, `requirementFields` необязательны. Ограничения применяются к поиску и чтению. Указывайте HTTPS-адреса, включая базовый путь Confluence. Несколько элементов массива дают выбор подключения внутри плитки.

Для Server/Data Center доступны `webSession` и `personalAccessToken`. Mimic открывает отдельное окно входа либо нативную форму токенов, проверяет доступ к каждому сервису и сохраняет учётные данные в macOS Keychain.

Для Cloud задайте `deployment: "cloud"`, `authentication: "oauth"`, адреса `https://team.atlassian.net` и `https://team.atlassian.net/wiki`. Mimic использует официальный Rovo MCP, браузер, PKCE и разрешения чтения/поиска. Организация должна разрешать доступ Rovo MCP. Живой Cloud-вход и чтение пока не квалифицированы. [Каталог и условия доступа Atlassian](https://developer.atlassian.com/cloud/rovo-mcp/guides/supported-tools/).

Вход запускается только кнопкой «Подключить». Автоматическое открытие панели не показывает авторизацию. Секреты не входят в профиль и не передаются панели или агенту. Смена адресов требует нового входа. «Отключить» удаляет сохранённый вход и кэш подключения.

## Документы и отчёт

Автоматически загружается список документов из ссылок задачи. Строка документа открывает оригинал в браузере; кнопка справа копирует ссылку этой страницы. «Читать здесь» загружает текст выбранной страницы порциями. Поиск Confluence доступен внутри плитки; оригинал открывается в браузере.

Отметьте нужные завершённые сборки, тесты или операции с Simulator и нажмите «Подготовить». Mimic не запускает проверки ради отчёта. Вердикт тестов берётся из доступных доказательств, устаревание исходников отмечается отдельно. Успех операции с Simulator не подтверждает выполнение критериев задачи.

Черновик редактируется и копируется для ручной отправки. В Codex «Дополнить с агентом» передаёт выбранный черновик в текущий чат; в macOS копируется запрос для агента. Агент по запросу сопоставляет diff и критерии. Mimic не публикует комментарии и не изменяет задачи или страницы.

## Команды агента

Доступны `get_work_context`, `jira_get_issue`, `jira_search`, `jira_get_comments`, `confluence_search`, `confluence_get_page`, `get_work_report`. Они используют подключение текущего проекта. Поиск принимает текст, чтение — ключ или ссылку на настроенный сервис. Продолжение ответа задаётся через `cursor` или `offset`. Отчёт принимает выбранные `evidenceIDs` из доступных результатов.

Автоматический контекст передаётся приватно интерфейсу MCP Apps. Агент получает содержимое после явного вызова команды. Внешний текст помечен как недоверенные данные.

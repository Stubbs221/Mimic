Имена файлов `release-160-*` оставлены для совместимости ссылок. Заменённые изображения показывают текущий интерфейс с нейтральными данными. Встроенные иллюстрации HTML, PDF и offline ZIP в `docs/releases` также обновлены; архивный текст использует общие названия инструментов. В HTML и PDF есть примечание о дате обновления иллюстраций.

Новые PNG содержат автора Василий Маслов и дату 23.10.2026. Пиксели получены прямой отрисовкой интерфейса; командные подписи и реальные аккаунты не использовались. Иллюстрации не квалифицируют живые операции, видеопроизводительность, системные разрешения или чужое оборудование.

# Изображения Mimic

Реальный UI, снятый 08.10.2026. Оригиналы и журнал обработки хранятся приватно; в Git включены только готовые изображения.

| Файл | Происхождение |
| --- | --- |
| `mimic-panel.png`, `tools.png` | Установленный Mimic 1.4.0/140, Tile Grid. |
| `codex-panel.png`, `simulator.png` | Настоящая панель Codex из development-сборки 1.3.1 с Tile Grid; Simulator показывает тестовое приложение «Проверка Mimic». Это не квалификация финальной видеопроизводительности 1.4.0. |
| `readme-hero-ru.png`, `readme-hero-en.png` | Композиция из очищенных реальных экранов и фирменного знака Mimic. |
| `badge-*.svg` | Декоративные плашки версии, платформы, архитектуры и лицензии; не результаты CI. |
| `updates.png` | Ранее снятый экран настроек обновлений с демонстрационными данными; в новом README не используется. |

Обработка без AI: обрезка, уменьшение, непрозрачные заливки непосредственно в пикселях. Скрыты рабочие идентификаторы, ветки, статистика использования и чувствительные подписи. Терминал Bootstrap показывает встроенный пример, а не сохранённый рабочий вывод. Стрелки порядка избранного — настоящие кнопки приложения. PNG содержит автора и дату создания; исходных скрытых слоёв в нём нет.

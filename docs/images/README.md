# Изображения Mimic

Обновлены 09.10.2026 для 1.5.0/150. Оригиналы и журнал обработки хранятся приватно; в Git только готовые изображения.

| Файл | Происхождение |
| --- | --- |
| `mimic-panel.png`, `tools.png`, `builds-native.png`, `updates.png` | Реальные экраны установленного нотарифицированного Mimic 1.5.0/150. Проектные действия ради съёмки не запускались. |
| `codex-panel.png`, `builds.png`, `tests.png`, `simulator.png` | Свежий рендер точного bundled HTML релизного SHA с синтетическими фикстурами. Simulator показывает встроенный демонстрационный экран. Это preview UI, не live-сессия Codex или устройства и не квалификация видеопроизводительности. |
| `readme-hero-ru.png`, `readme-hero-en.png` | Композиция из реального macOS UI, явно подписанного Codex preview и знака Mimic. |
| `badge-*.svg` | Декоративные плашки версии, платформы, архитектуры и лицензии. |

Обработка без AI: обрезка и непрозрачные заливки непосредственно в пикселях. Скрыты рабочие идентификаторы, ветки, статистика и история запусков. Bootstrap показывает встроенный пример. PNG содержит автора и дату создания; скрытых слоёв нет. Снимок текущей MCP-панели недоступен в используемом screenshot backend; опубликован явно обозначенный preview той же версии HTML.

Материалы 1.4.0 с прежними встроенными изображениями сохранены в `docs/releases/1.4.0`.
